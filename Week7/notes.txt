angular.json:
Configuration file for Angular CLI. It defines project settings, build options, assets, styles, and scripts.

tsconfig.json:
Main TypeScript configuration file that controls compiler options for the Angular project.

tsconfig.app.json:
TypeScript configuration specifically for the application source files inside src folder.

package.json:
Contains project metadata, dependencies, npm scripts, and Angular packages required by the application.

src/main.ts:
The entry point of the Angular application. It bootstraps the root component and starts the application.

src/app/app.config.ts:
Provides application-level configurations such as dependency injection providers and Angular settings.

src/app/app.ts:
Root Angular component containing component logic, selector, and metadata.

src/index.html:
The main HTML page where Angular application is loaded using the root selector.

dist/main.js:
Contains the compiled JavaScript bundle generated from Angular TypeScript files.

Angular Budget:
Controls the maximum size of generated bundles. 
maximumWarning gives warnings and maximumError stops the build when size exceeds limits.
